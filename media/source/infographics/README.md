# Infographic source specs

The SVGs in `media/exports/` are generated by `scripts/render_infographics.py`.
The small YAML files beside this README are editorial briefs (the renderer does not read them): each
records the question, audience, and claim that the drawing must teach. Keep the
wording in the spec and the text equivalent in `docs/learn/infographics.md` in
sync when changing an illustration.
