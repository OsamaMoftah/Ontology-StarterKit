# Life-science annotation evidence

This synthetic pack teaches the distinction between an annotation, a biological term and the evidence supporting an assertion. It is inspired by the Gene Ontology workflow but contains no redistributed GO terms or real scientific claims. Missing annotation evidence is an evidence gap, not proof of absence.

The example uses the valid external identifier shapes `GO:0008150`, `ECO:0000269`, and `NCBITaxon:9606` while keeping the labels and records synthetic. The source register pins the identifier reference version and retrieval date. Term selection, taxon scope, evidence code, source span, and review state are separate fields; a missing annotation is not a negative biological finding. Scientific review remains a human gate outside automated SHACL checks.
