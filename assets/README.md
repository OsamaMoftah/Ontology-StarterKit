# Visual assets

Generated SVGs live in `media/exports/` and are derived from the reviewed Mermaid sources in each example pack. Every asset has an accessible title, description and text equivalent. Run:

```bash
python scripts/render_diagrams.py examples/hello-ontology/model.mmd media/exports/hello-model.svg
```

Keep factual labels and relationships synchronized with the pack fixture. Decorative illustrations, screenshots and third-party logos require a separate attribution and permissions record.
