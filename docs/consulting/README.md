# Life-sciences consulting path

This path is for strategy, data, technology and risk teams advising pharma, biotech, medtech, diagnostics and research organizations. The [use-case catalogue](use-cases.md) contains 12 decision-oriented workstreams, and the runnable packs begin with synthetic data.

## Engagement pattern

1. Frame one client decision and a baseline.
2. Register permitted sources, versions and access restrictions.
3. Agree definitions, identifiers, time rules and evidence standards with domain reviewers.
4. Build a small validated slice and encode competency questions.
5. Compare results with the client's manual process.
6. Transfer the model, evidence register, unresolved questions and maintenance owner.

Useful deliverables are an executive decision brief, claim-to-source register, source-access register, term glossary, mapping log, validation report, evaluation set and handoff checklist.

## Start with these cases

| Case | Decision | Starter artifact |
|---|---|---|
| Therapeutic-area landscape | Which assets and evidence match a defined indication? | `consulting-evidence-room` pack |
| Asset diligence | Which claims are supported, conflicting or unknown? | Claim/evidence query and review queue |
| Master-data harmonization | Which source records refer to the same entity? | Reviewed alias and mapping table |
| Quality/supply change impact | Which products and documents may be affected? | Dependency graph with review status |
| Clinical operations | Which protocol/site requirements are documented? | Versioned protocol/site fixture |

Use cases are proposed applications, not claims of adoption by McKinsey, PwC, Strategy&, or another firm. Public firm sources support the problem areas, not this repository's results. Keep patient data, client records and licensed terminology out of the public examples.

## Value measures

Measure expert-reviewed evidence precision, unsupported-claim rate, false merges, stale-source rate, task completion time, review effort, adoption and recurring curation cost. Separate freed capacity from cash savings. A graph does not prove efficacy, regulatory compliance, legal title, cost effectiveness or clinical advice.
