# A short history of computational ontology

This timeline separates standards, business vocabularies, life-science communities and modern retrieval applications. The dates link to primary or project sources. A milestone is historical context, not proof that every later system uses the same technology.

See [ontology in business](ontology-in-business.md), [ontology in life sciences](ontology-in-life-sciences.md), and [ontology in AI](ontology-in-ai.md).

The claim-by-claim source map is [`source-register.yaml`](source-register.yaml).
Run `python scripts/check_review_register.py` to verify that every historical
source URL is mapped to the document that makes the claim.
