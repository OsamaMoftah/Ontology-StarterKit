# Glossary

**Class:** a concept in the model, such as `Person`.

**Instance:** a represented entity, such as `Maya`.

**Relation:** a typed connection between entities, such as `manages`.

**Ontology:** a formal, shared conceptual model with terms and relationships.

**RDF:** a graph data model expressed as subject, predicate and object statements.

**OWL:** a language for ontology semantics and declared axioms.

**SHACL:** a language for validating RDF graphs against shapes and constraints.

**Competency question:** a question the model is required to answer, encoded as a test.

**Evidence record:** a source-linked assertion or record supporting a claim.

**Provenance:** information about where a statement came from, what activity produced it and who was responsible.

**Open-world assumption:** missing information does not automatically mean false.

**GraphRAG:** retrieval and generation that uses graph structure; it may use an ontology but is not synonymous with one.
