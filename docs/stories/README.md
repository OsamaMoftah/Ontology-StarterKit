# Stories: ontology under pressure

These are fictional, composite stories written for workshops. Names, metrics,
and records are invented. Each story points to a runnable pack and calls out
the decision boundary where a graph still needs a human reviewer.

- [Three teams, three Customers](three-teams-three-customers.md) — align a commercial vocabulary before a migration.
- [The evidence room at Northstar](service-incident.md) — keep a consulting recommendation honest when sources disagree.
- [Two labs, one question](two-labs-one-question.md) — preserve annotation context across life-science datasets.
